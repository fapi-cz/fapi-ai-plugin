# Palette library

Color roles adapted from the 56-palette tasteskill v2 library used by Super's site-agent. See the [MIT notice](LICENSE-tasteskill). Read this library when choosing a new visual direction; a supplied brand or measured reference takes precedence.

Choose by the subject and composition, using tags to narrow the field. Dark grounds need explicit light Heading/Text ink and readable treatment of fixed-style components. Use the accent sparingly for the main action. `Fields` gives optional whole-section background / ink pairs. Surface is a quieter background, not a separate card component. The table omits muted text: use the full ink for reading text.

Check actual text/background contrast before applying a pair, including text on surface, button labels and links. These source colors are design candidates, not a contrast certification. A field's ink belongs only on that field; do not carry it onto another background. Apply through the supported properties described in [Sales-page design](sales-page-design.md).
